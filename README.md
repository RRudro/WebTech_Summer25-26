🌐 WebTech — Summer 25–26
Course: Web Technologies  |  Semester: Summer 2025–2026
Department: Computer Science  |  Institution: American International University-Bangladesh (AIUB)

📋 Course Overview
This course introduces students to the fundamentals and advanced concepts of modern web technologies. Students will build practical skills in front-end and back-end development, covering standards-based HTML/CSS, interactive JavaScript, responsive design, and server-side scripting. By the end of the semester, students will be capable of designing and deploying full-stack web applications.
